# SG–JB Checkpoint Cams

Live LTA traffic camera images at the Woodlands and Tuas checkpoints (from [data.gov.sg](https://data.gov.sg)), plus a route comparison from anywhere in Singapore to **JB Sentral** via the Woodlands Causeway or the Tuas Second Link.

- Cameras: `api.data.gov.sg/v1/transport/traffic-images` (auto-refresh every 60 s)
- Start-point search: OneMap
- Routing: OSRM (free-flow times; checkpoint queues not included)

Run locally: `node server.js` → http://localhost:8000
